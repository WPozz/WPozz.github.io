EU HEREDITARY: Anatomical-Aware SSL

PyTorch C-JEPA VICReg TokenLearner FOMO-300K SLURM

Scientific Objective

Extract latent, interpretable phenotypic representations from 3D MRI scans without diagnostic annotations (unsupervised), enabling downstream clinical phenotype clustering within the EU HEREDITARY framework.

Architecture & Methodology

  • Hybrid SSL Paradigm: Combined Contextual Joint-Embedding Predictive Architecture (C-JEPA) with intra-subject VICReg variance-invariance-covariance regularization to mitigate representation collapse.
  • CNN-Transformer with TokenLearner: Multi-scale 3D CNN feature extraction compressed by a TokenLearner module into anatomically localized tokens processed by Transformer self-attention blocks.
  • HPC Infrastructure: Large-scale processing of the FOMO-300K dataset (318,000+ MRI volumes) with automatic mixed precision (AMP) across multi-GPU Linux cluster nodes using SLURM.
  • Privacy & Anonymization: Automated anatomical defacing pipeline via SynthSeg+ for strict clinical compliance.

Clinical NLP – Medical Transcription Classification

Transformers Bio-ClinicalBERT PyTorch Focal Loss CUDA AMP

Project Overview

Automated multi-class classification of complex medical transcriptions into 13+ clinical specialties to streamline hospital documentation workflows and clinical triage.

Key Technical Highlights

  • Fine-tuned biomedical domain Transformer model (Bio-ClinicalBERT).
  • Implemented a custom weighted Focal Loss function to mitigate severe class imbalance between rare and common medical specialties.
  • Achieved 91% Top-3 Accuracy validated through comprehensive Precision-Recall curves and multi-class confusion matrices.
  • Accelerated CUDA training loops using PyTorch Automatic Mixed Precision (AMP).
